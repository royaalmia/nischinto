# 🚀 Nischinto (নিশ্চিন্ত) CRM & E-commerce Operating System
> **"ব্যবসা আপনার, অটোমেশন নিশ্চিন্তের"**

Nischinto (নিশ্চিন্ত) হলো বাংলাদেশের ই-কমার্স ব্যবসায়ীদের জন্য তৈরি নেক্সট-জেনারেশন ফুল-স্ট্যাক অটোমেশন, ফ্রড প্রিভেনশন, স্মার্ট কুরিয়ার রাউটিং এবং **AI অটো অ্যাড প্ল্যাটফর্ম**—যা BizMation, EcomDrive বা Posware-এর চেয়েও অনেক বেশি শক্তিশালী ও আধুনিক।

---

## 🌟 এক্সক্লুসিভ ফিচারসমূহ (Key Features)

### ১. লাইভ স্মার্ট অর্ডার হাব (Omnichannel Order Hub)
- **ইনকমপ্লিট অর্ডার ক্যাচার (Abandoned Cart Tracker):** কাস্টমার চেকআউট ফর্মে নাম-নম্বর টাইপ করে সাবমিট না করে কেটে দিলেও তাৎক্ষণিক ডেটা সেভ হয় এবং ড্যাশবোর্ডে চলে আসে।
- **১-ক্লিক হোয়াটসঅ্যাপ রিকভারি:** ড্রপ-অফ কাস্টমারদের সরাসরি হোয়াটসঅ্যাপে পারসোনালাইজড অফার মেসেজ পাঠানো।
- **ডেটা গার্ড (Anti-Theft Phone Number Masking):** কল সেন্টার এজেন্টরা কাস্টমারের সম্পূর্ণ ফোন নম্বর দেখতে বা এক্সপোর্ট করতে পারবে না (যেমন: `01712****78`), ফলে কর্মচারীদের ডেটা চুরির ঝুঁকি শূন্য।

### ২. AI অটো অ্যাড ম্যানেজার (Autonomous Meta & TikTok Ads)
- **১-ক্লিক ক্যাম্পেইন লঞ্চ:** প্রোডাক্ট সিলেক্ট করে শুধু দৈনিক বাজেট দিলে AI স্বয়ংক্রিয়ভাবে হাই-কনভার্টিং বাংলা সেলস কপি, ক্যাচি হেডলাইন ও ১% Lookalike Audience তৈরি করে Meta Marketing API দিয়ে লাইভ করে দেয়।
- **আউট-অফ-স্টক অটো পজ (Stock Sync):** ইনভেন্টরিতে কোনো প্রোডাক্টের স্টক ০ হয়ে গেলে AI সঙ্গে সঙ্গে ফেসবুকের বিজ্ঞাপন বন্ধ করে দেয়, যাতে বাজেটের অপচয় না হয়।
- **অটো-কিল সুইচ (ROAS Guard):** কোনো অ্যাড বেশি টাকা খরচ করে সেল না আনলে AI নিজে থেকেই অ্যাড বন্ধ করে দেয়।

### ৩. সেন্ট্রাল কুরিয়ার ফ্রড গার্ড (Multi-Vector Risk Scoring)
- কাস্টমারের ফোন নম্বর দিয়ে Steadfast, Pathao ও RedX-এর সেন্ট্রাল হিস্টোরি ক্রস-ম্যাচ।
- কাস্টমারের পার্সেল রিসিভ ও রিটার্নের অনুপাত অনুযায়ী **০-১০০ রিস্ক স্কোর** এবং পরামর্শ (Safe, Medium, High Risk)।
- ঝুঁকিপূর্ণ কাস্টমারদের ক্ষেত্রে অটোমেটিক অগ্রিম ডেলিভারি চার্জ নেওয়ার গেটওয়ে রিকমেন্ডেশন।

### ৪. বাংলা AI ভয়েস কলিং (Conversational Bengali Voice Agent)
- কোনো কর্মী ছাড়াই মানুষের মতো মিষ্টি বাংলায় কাস্টমারকে কল করে সাইজ, কালার ও ঠিকানা কনফার্ম করা।
- কল সম্পন্ন হলে স্বয়ংক্রিয়ভাবে অর্ডার স্ট্যাটাস `CONFIRMED`-এ রূপান্তর এবং পূর্ণাঙ্গ ট্রান্সক্রিপ্ট সংরক্ষণ।

### ৫. স্মার্ট কুরিয়ার রাউটিং ও সেটেলমেন্ট (Courier Reconciliation)
- নির্দিষ্ট জেলায় (যেমন: ঢাকা মেট্রো বনাম দেশের অন্যান্য থানা) কোন কুরিয়ার দ্রুত ডেলিভারি দেয়, তা বুঝে স্বয়ংক্রিয়ভাবে **Steadfast** বা **Pathao** নির্ধারণ।
- ১-ক্লিকে বাল্ক বুকিং ও ট্র্যাকিং কোড জেনারেশন।
- কুরিয়ার কোম্পানি ব্যাংকে টাকা পাঠানোর পর ডেলিভারি ফি ও ১% COD চার্জ হিসাব মিলিয়ে দেওয়া।

### ৬. আসল লাভ-ক্ষতি অ্যানালিটিক্স (True Net Profit)
- নিট লাভ = (বিক্রয়মূল্য) - (ক্রয়মূল্য COGS + কুরিয়ার চার্জ + ফেসবুক অ্যাড স্পেন্ড + প্যাকেজিং খরচ)।

## 🛠️ টেকনোলজি স্ট্যাক (Tech Stack)
- **Frontend & Backend:** Next.js 14 (App Router), TypeScript, Tailwind CSS, Lucide Icons
- **Database & ORM:** Prisma ORM, SQLite (লোকাল ডেভেলপমেন্ট) / PostgreSQL (প্রোডাকশন রেডি)
- **Services:** Courier Engine (Steadfast, Pathao), AI Ad Manager Engine, Bengali AI Voice Simulator, Fraud Detection Engine

## 🏃 কীভাবে রান করবেন (Getting Started)

### ১. ডিপেন্ডেন্সি ইনস্টল (ইতিমধ্যে সম্পন্ন):
```bash
npm install
```

### ২. ডেটাবেস প্রিপেয়ার ও সিড:
```bash
npx prisma db push
node prisma/seed.js
```

### ৩. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```
ব্রাউজারে ওপেন করুন: `http://localhost:3000`

## 🌐 ক্লাউডফ্লেয়ার ও ডোমেন সেটআপ (Cloudflare Setup Guide)
1. আপনার কেনা ডোমেনটির (যেমন: `nischinto.com`) DNS Nameserver পরিবর্তন করে Cloudflare-এ পয়েন্ট করুন।
2. Cloudflare-এ **SSL/TLS encryption mode: Full (strict)** সিলেক্ট করুন।
3. ফ্রন্টএন্ড Vercel-এ হোস্ট করে Cloudflare CNAME পয়েন্ট করুন, অথবা একটি $৬/মাসের VPS (DigitalOcean/Hetzner)-এ Docker দিয়ে চালান।
